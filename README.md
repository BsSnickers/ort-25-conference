# Международная научно-практическая конференция к 25-летию ОРТ
### «Равный шанс – большое будущее» / «Тең мүмкүнчүлүк – кең келечек» / “Equal Opportunity – Great Future”

Официальный презентационный лендинг международной научно-практической конференции по вопросам качества и справедливости отбора в высшую школу, приуроченной к 25-летию Общереспубликанского тестирования (ОРТ / ЖРТ).

- **Организатор:** Центр оценки в образовании и методов обучения (ЦООМО / БББаОБ / CEATM)
- **При поддержке:** Министерства науки, высшего образования и инноваций Кыргызской Республики и Министерства просвещения Кыргызской Республики
- **Дата проведения:** 29 октября 2026 года
- **Место проведения:** г. Бишкек, Кыргызская Республика

---

## Стек технологий

- **React 19**
- **TypeScript**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Vite 6**
- **Firebase Firestore** (коллекция `conferenceRegistrations` для регистрации участников)
- **Lucide React** (лаконичные академические иконки)
- **jsPDF** (генерация и печать официального информационного письма)

---

## Архитектура и дизайн

Дизайн-система выстроена по канонам **швейцарского делового модернизма (Swiss Corporate Minimal)**:
- Полноформатные полосы во всю ширину экрана (**Full-Bleed Strips**) без скруглений внешних блоков;
- Геометрическая сетка с разделителями ровно **1px** (`border-zinc-200`, `border-white/20`, `border-zinc-800`);
- Монументальная гротескная типографика (заголовки 70px) с официальными слоганами;
- Институциональная палитра юбилея: глубокий темно-синий (**Deep Navy** `#151A2C`), угольный оверлей (**Charcoal** `#2F2E2E` 85%) поверх архивных фото, чистый белый (**Clean White** `#FFFFFF`) и светлый оттенок слоновой кости (`#F8FAFC`);
- Мгновенное переключение 3 языков (**Кыргызча**, **Русский**, **English**) через `LanguageContext` с динамической адаптацией институциональных названий (БББаОБ / ЦООМО / CEATM; ЖРТ / ОРТ / ORT).

## Структура секций

1. **Pinned Header** — логотип организации, бейдж «25 ЖЫЛ / ЛЕТ», якорное меню, селектор `KY | RU | EN`, кнопка «Регистрация».
2. **Hero Banner Strip** — фотоархив зала под графитовым оверлеем `#2F2E2E`, официальный заголовок, метаданные (Бишкек, 29 октября 2026), кнопки действий.
3. **Концепция и повестка** — исторический контекст 25-летия системы тестирования и цели конференции.
4. **Об институте ЦООМО / БББаОБ** — сплит-лейаут об истории создания независимого отбора в 2002 году, борьбе с коррупцией и миссии меритократии.
5. **Ключевые показатели (Metrics)** — 4 колонки: 25 лет прозрачного отбора • 1 000 000+ участников • 100% меритократия • 9 научных направлений.
6. **Спикеры форума** — 3 слота `[БЛАНК]` для докладчиков пленарных и экспертных сессий.
7. **9 официальных направлений (Tracks Matrix)** — строгая сетка 3x3 с описаниями 9 официальных научных треков из информационного письма.
8. **Организаторы и партнеры** — блок в Navy Blue с 3 официальными структурами: ЦООМО / БББаОБ / CEATM, МНВОИ КР, Минпросвещения КР.
9. **Параллакс-разделитель** — широкоформатная архивная панорама экзаменационной аудитории.
10. **Хроника 25-летия (Архив)** — 3 слота `[БЛАНК]` архивных материалов оргкомитета.
11. **Регистрация участников** — интерактивная форма подачи заявки с валидацией и записью в Firestore `conferenceRegistrations`.
12. **Подвал (Footer)** — 4-колоночная сетка с реквизитами, контактами и кнопкой скачивания информационного письма.

## Запуск и разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Проверка типов TypeScript
npx tsc --noEmit

# Сборка production bundle
npm run build
```
